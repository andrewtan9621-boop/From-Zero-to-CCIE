# Assign an IPv4 Network Address to an Interface

![[show ip int br.png]]

OK? column: [legacy](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD-%E6%B1%89%E8%AF%AD-%E7%AE%80%E4%BD%93/legacy?q=legacy+) feature of the command, it says whether or not the IP address is valid or not. On modern devices, it won’t let you assign invalid IP addresses, so you should never see ‘NO’ in this column 

Method column: This indicates the method by which the interface was assigned an IP address. 

Status column: Considered as Layer 1 status of the interface. If the interface is enabled, you should see ‘up’ here. 

**’administratively down’ means the interface has been disabled with the ‘shutdown’ command, this is the default status of Cisco router interfaces.**

**Cisco switch interfaces are NOT administratively down by default.**

Protocol column: This is the Layer 2 status. Because the interfaces are down at Layer 1, Layer 2 cannot operate. 


```
## to enter priviliged EXEC mode
Router> enable

## to enter configure mode
Router# configure terminal

## to enter interface configure mode
Router(config)# interface g0/1

Router(conf-if)# ip address 10.255.255.254 255.0.0.0

## remember to no shutdown the interface
Router(conf-if)# no shutdown
```

![[assigned.png]]

The ipv4 address has been assigned correctly.
